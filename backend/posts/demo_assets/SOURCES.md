# Imagens da demonstração

Fotos ilustrativas para os anúncios fictícios criados por `seed_demo_data`.
Não retratam ofertas reais nem comprovam marcas, modelos ou estado dos itens.
Os avatares das contas fictícias são gerados localmente com iniciais.

As fotos já usadas no frontend foram copiadas para esta pasta para que o comando
funcione no container do backend sem acesso ao filesystem do frontend.
